# AI Study Planner

An AI-powered study planning web application that creates personalized study schedules based on a student's subject, exam date, and available study time.

## Features

- AI-generated personalized study plans
- Day-by-day topics and study tasks
- Estimated study time for each day
- Revision strategy generated by AI
- Task completion tracking
- Automatic progress percentage
- Progress bar
- Progress saved in browser local storage
- Loading and skeleton states
- Empty state for new users
- Error handling and retry support
- Exam-date validation
- Responsive interface
- Keyboard and screen-reader accessibility improvements

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Hugging Face Inference API
- Local Storage
- App Router

## How It Works

1. Enter the subject you want to study.
2. Select your exam date.
3. Enter the number of study hours available per day.
4. Click **Generate Study Plan**.
5. The application sends the information to the AI backend.
6. Hugging Face generates a structured study plan.
7. The plan is displayed as a day-by-day schedule.
8. Students can mark individual tasks as completed.
9. Progress is automatically calculated and saved.

## AI Integration

The application uses the Hugging Face Inference API to generate structured study plans.

The AI is instructed to return:

- Overall plan title
- Summary
- Number of study days
- Daily study hours
- Topics for each day
- Actionable study tasks
- Estimated hours
- Revision strategy

The backend validates the generated response and returns it to the frontend as structured JSON.
